# Зомби-сервер CS 1.6

Сборка сервера Counter-Strike 1.6 с модом «Зомби-чума» (Zombie Plague 4.4) и
сайт для продажи привилегий к нему.

Проект собирается **из исходников и описи**, а не копируется готовой папкой.
Причина простая: готовые сборки из интернета приходят с чужой рекламой, чужими
админами и плагинами неизвестного происхождения — всё это находится в
`docs/AUDIT.md`, где разобрано с десяток популярных сборок. Здесь вместо этого
лежит опись того, что ставится, и инструменты, которые её выполняют.

## Что внутри

| Каталог | Что это |
|---|---|
| `custom/` | Плагины, конфигурация и отобранный контент сервера |
| `site/` | Витрина привилегий, панель выдачи, просмотр моделей в браузере |
| `tools/` | Сборка, аудит чужих сборок, работа с моделями, заливка на хостинг |
| `docs/` | Устройство сервера, аудит сборок, подключение сайта |
| `upstream/` | Опись того, что скачивается со стороны (сами файлы не хранятся) |
| `quarantine/` | Разобранные чужие сборки: в репозитории только `meta.json` |

## Как собрать

Нужен Node.js. Игровые двоичные файлы и чужие сборки в репозитории не лежат —
они скачиваются:

```
node tools/fetch-upstream.mjs      # движок, AMX Mod X, мод
node tools/assemble.mjs            # собрать сервер в server/
node tools/build-fastdl.mjs        # дерево раздачи файлов игрокам в dist/fastdl
run-local.cmd                      # локальный прогон на Windows-двоичных файлах
```

Локальный прогон — только проверка, что стек поднимается: боевой сервер идёт на
Linux.

## Сайт

Живёт отдельно от игрового сервера и ничего о нём не знает. Привилегии
попадают в игру через базу: `admin_sql.amxx` при старте карты выполняет один
запрос без условий, а `zm_admins` — не таблица, а **представление**, которое
само отбрасывает просроченные записи. Отсюда три следствия: срок действия
обеспечивает база, выдача мгновенна (сайт шлёт `amx_reloadadmins` по RCON), а
падение сайта возвращает сервер к `users.ini` и не отрезает владельца от
управления.

Подробности — в `site/README.md`, подключение к серверу — в
`docs/2026-08-11-site-integration.md`.

## Паролей здесь нет

`custom/db.ini`, `custom/admins.ini` и `site/private/config.php` перечислены в
`.gitignore` — в них доступ к базе, к RCON и к кассе. В репозитории лежат
только образцы этих файлов.

## Происхождение содержимого

Модели, звуки и часть плагинов взяты из публичных сборок Zombie Plague и
переработаны: вычищена чужая реклама, приведены к рабочим ограничениям
GoldSource. Источник каждого файла записан в `custom/content/ПРОИСХОЖДЕНИЕ.txt`.
Права на исходные материалы принадлежат их авторам.
